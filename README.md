# Vue Portfolio Website

A modern, responsive portfolio website built with Vue.js 3 and Vite.

## Features

- **Home Page**: Hero section with background image and centered name/profession
- **About Page**: Headshot and personal introduction
- **Experience Page**: Timeline-style work experience display
- **Projects Page**: Project cards with descriptions and links
- **Contact Page**: Contact information and social links
- **Responsive Design**: Mobile-friendly layout
- **Modern UI**: Clean, professional design with smooth animations

## Setup

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

## Customization

### Personal Information

Update the following files with your information:

- `src/views/Home.vue`: Change name and profession
- `src/views/About.vue`: Update profile image and bio
- `src/views/Experience.vue`: Modify work experience data
- `src/views/Projects.vue`: Add your projects
- `src/views/Contact.vue`: Update contact information

### Images

Add your images to the `public` folder:

- `hero-bg.jpg`: Background image for home page
- `profile.jpg`: Your headshot for about page
- `project1.jpg`, `project2.jpg`, etc.: Project screenshots

### Styling

Modify `src/style.css` to customize colors, fonts, and layout.

## Technologies Used

- Vue.js 3
- Vue Router
- Vite
- CSS3 with Grid and Flexbox
- Responsive Design
